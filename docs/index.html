Semua yang dibutuhkan koperasi

Dari simulasi pinjaman sampai edukasi anggota — satu chatbot, semua jawaban.

💰

Simulasi Pinjaman

Hitung angsuran otomatis dengan metode flat rate. Tabel lengkap: pokok, bunga, total, sisa per bulan.

📋

Produk Koperasi

Informasi lengkap simpanan wajib, sukarela, berjangka, deposito, dan semua jenis pinjaman KSP.

🧠

Memory Percakapan

Ingat konteks chat sebelumnya. Semakin banyak ngobrol, semakin pintar dan personal jawabannya.

🎯

Domain Koperasi

Paham AD/ART, SHU, RAT, UU No. 25/1992, dan regulasi koperasi simpan pinjam Indonesia.

🎨

3 Gaya Bahasa

Cara Kerja

Simpel, cukup 3 langkah

Tidak perlu install apa pun. Buka browser, masukkan API key, langsung tanya.

1

Dapatkan Gemini API Key

Gratis dari Google AI Studio. Cukup login dengan akun Google, satu klik langsung dapat.

2

Buka KoperasiAI & Masukkan Key

Buka aplikasi, paste API key di sidebar. Pilih model (Flash/Pro), atur temperature & gaya bahasa.

3

Mulai Bertanya!

Ketik pertanyaan atau klik quick prompt. AI langsung merespon dengan informasi akurat seputar koperasi.
